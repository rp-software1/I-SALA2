Describe con tus palabras qué es un JWT y cómo fluye entre frontend y backend. No uses código — solo la idea. Si no puedes explicarlo sin mirar los apuntes, ¿qué parte no entendiste?
Un JWT es como un pase o credencial digital.
Cuando haces login:

El backend verifica tus datos
Si todo está bien, te da un token (JWT)
Luego:

El frontend guarda ese token
Cada vez que haces una petición, lo envías al backend
El backend:

Lee el token
Verifica si es válido
Si lo es → te deja acceder
Si no → te bloquea
