Al empezar el Día 1 de React construyeron un componente estático con props. Hoy conectaron un sistema completo con APIs reales. Describe en una sola oración qué aprendiste en cada fase — componentes, estado, efectos, consumo de API, navegación, estado global, conexión real.
Componentes: aprendí a crear componentes reutilizables y pasar datos mediante props.
Estado: aprendí a manejar datos dinámicos dentro de la aplicación usando estado.
Efectos: aprendí a usar efectos para ejecutar lógica cuando cambia el estado o se carga la app.
Consumo de API: aprendí a obtener datos desde un servidor usando herramientas como Axios.
Navegación: aprendí a moverme entre páginas usando rutas en la aplicación.
Estado global: aprendí a compartir datos entre varios componentes sin necesidad de pasarlos manualmente.
Conexión real: aprendí a trabajar con datos reales desde un backend en lugar de usar datos simulados.
